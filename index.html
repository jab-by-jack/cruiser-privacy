Instinct Cruiser privacy policy

Last updated: November 25, 2026

Instinct Cruiser is a Chrome extension that lets the user's own Instinct assistant work in the user's browser tabs.

What it handles. Only when the user has allowed it, the extension reads page content, takes pictures of a tab the user chose to share, and carries out actions the user approved. It keeps settings, allowed sites, access level and an activity history on the user's computer.

Where it goes. That information is sent only to the hub that the user paired with their own Instinct, using a pairing key the user typed in. It is not sent to the developer, advertisers or anyone else by the extension.

What we do not do. We do not sell data, use it for ads, use it to judge credit or lending, or use it for anything other than the single purpose of working for the user. We do not read passwords. Money, sending, deleting and sign-in steps always ask the user first.

Voice. Hands-free talking uses Chrome's on-device speech recognition and the voices on the user's computer. If a mode ever sends audio off the device, it asks the user first each time.

Control and deletion. The user can pause or stop any time, switch access to Off, remove sites, clear history in Settings, or remove the extension. Removing the extension deletes its local data. To ask about data held by the user's Instinct service, contact the user's Instinct provider.

Contact: open an issue on the Issues tab of this page's GitHub repository.
